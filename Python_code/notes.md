# 机器学习

## 概念

定义；作用；分类
> 分类：基于学习策略，学习方法，学习方式，学习目标，数据形式

统计机器学习三要素：
**模型**：模型在未进行训练前，其可能的参数有多个甚至无穷多个，故可能的模型也有多个甚至无穷个，这些模型构成的集合就是假设空间；
**策略**：从假设空间中挑选出参数最优的模型的准则。模型的分类或预测结果与实际情况的误差（损失函数）越小，模型就越好。***所以策略就是误差最小。***
**算法**：从假设空间中挑选模型的方法。最优化问题。

## 机器学习理论基础

### 过拟合和欠拟合

机器学习基本问题：利用模型对数据进行拟合。目标是能够对未曾在训练集出现的样本进行正确的预测。
模型对训练集数据的误差：经验误差，对测试集的误差称为泛化误差。
**泛化能力**：能力强的是好模型，对新鲜样本的适应能力。（与训练次数无关联）

> 过拟合，获取更多的训练数据，减少输入的特征数量，选取合适的停止训练标准，保留验证数据集，获取额外数据交叉验证（神经网络中可以用权值衰减），目标函数优化时正则化
欠拟合，增加有价值的特征，**增加多项式特征**，减少正则化参数，使用非线性模型，使用集成学习方法，调整模型的容量（拟合各种函数的能力，低可能很难拟合数据集）

交叉验证数据集，与训练数据集，测试数据集并列，划分三种数据集是一个科学的方法（工程上并不需要选择模型，而是获取更多的数据）

### 损失函数、成本函数、目标函数

#### 损失函数

**在单个样本上，是指一个样本的误差**
通过最小化损失函数求解和评估模型。
损失函数针对回归问题和分类问题采用不同的函数。

#### 成本函数

**在整个训练集上，是所有样本误差的平均**，即所有损失函数值的平均

#### 目标函数

指最终需要优化的函数，一般来说是经验风险+结构风险，即**代价函数+正则化项**

### 模型性能度量

均方误差
错误率，精度（错误/正确的样本数占总比）
查准率（$TP\over TP+FP$），查全率（$TP\over TP+FN$）
TP（真正），FP（假正），FN（假反），TN（真反）
P（查准率）—R（查全率）曲线，如果两个模型的P-R曲线图相交，就不能通过该曲线进行测评。
$$ F1 = \frac {2*P*R}{P+R} = \frac {2*TP}{样例总数+TP-TN} $$

> F1是基于查准率与查全率的调和平均(加权平均)，即$\frac {1}{F1} = \frac12*(\frac 1P* \frac 1R)$

学习曲线：偏差与方差

$$ 误差 = 方差 + {偏差}^2 + 噪声 $$
> 一般，随着模型复杂度的增加，方差会逐渐**增大**，偏差会逐渐**减小**

ROC与AUC
ROC曲线中，x轴代表假正例率（单位是$\frac 1{反例的个数}$），y轴代表真正例率（单位是$\frac 1{正例的个数}$）
分数越高，正例的可能性越大，越靠近(0,1)坐标的ROC曲线，性能越好
(计算方式略)

AUC即ROC曲线与x轴包围面积的大小，是一个概率值，AUC越大，性能越好。
$$AUC = \frac12 \sum_{i=1}^{m-1}(x_{i+1}-y_i)*(y_i+y_{i+1})$$

scikit-learn中score(X_test,y_test)，分数越高，准确性越高，误差越小，成本越低。

## 回归分析

确定两种或两种以上变量间相互依赖定量关系的一种统计分析方法。根据自变量的多少分为一元线性回归和多元线性回归；根据自变量和因变量之间的关系类型，分为线性回归和非线性回归分析。
